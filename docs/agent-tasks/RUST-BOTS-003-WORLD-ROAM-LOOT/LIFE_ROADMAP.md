# Rust Phantom Life — долговременные требования владельца (НЕ всё делать в 003)

## Долгосрочная цель

~50–100 самостоятельных персонажей на личном соло-сервере, ощущение настоящих живых игроков, а не статика/патруль монумента. Начать на пляже с камнем/факелом; перемещаться по открытому миру и дорогам; добывать дерево/камень/руду, бить бочки, лутать ящики, трупы, карты доступа/краты, собирать экипировку; крафтить, изучать blueprints, добывать scrap, строить и использовать верстаки, печи/переработчики.

## База и потеря имущества

- Дом определяется семантически по real building entities + owner/group + TC(s), но не просто координате и не только одному шкафу. Разделять группы с несколькими внешними TC.
- Стройка по валидируемым базовым чертежам (малый стартовый дом → улучшение), уплата upkeep из **реальных** запасов, учёт привилегий, дверей/гаражек/кодовых замков/сохранения и добычи.
- Home-local navigation: room graph/portals (двери/лестницы/проёмы) поверх RustNav. Проверять locked/open/closed/destroyed/blocked. Признаки мест хранения/производства: TC, спальня/спалки, коробки с категориями ресурсов/оружия/расходников, верстак, печи.
- Смерть: реальные труп и дроп инвентаря, возрождение на разрешённой спалке/кровати или пляже по игровым правилам и cooldown; сохранение личности, наученных blueprints/социальных связей, имущества дома. При потере TC — попытаться защитить/вернуть или переселиться и фармить на новый дом; не бесплатное воскрешение ресурсов.
- Дом обороняется: свои/чужие, грамотное оружие и cover, помощь союзников, не застревать за закрытыми гаражными дверями; иногда засадить у дома игрока/бота, но не бессмысленные бесконечные кемперы.

## Социальная жизнь и PvP

- 1–5 NPC в группах/гангах, личные отношения/память/смерти/обиды, общая база и ресурсы, приоритет native Rust clans при доказанной совместимости NPC IDs; без имитации чужих Steam ID. NPC-и воюют между собой и с человеком; союзники не стреляют в своих. Запрещены телепортации при игроке, всевидение/бесконечные патроны/невидимая добыча.
- 50–100 постоянных идентичностей; одновременно физически активных выбирать по performance; long-range simulation требует conservation и непрерывности истории, без незаметных читерских jumps при видимости игрока.

## Монументы и ивенты

- Обычные RT/дороги/контейнеры, учёные, карточки, fuse/считыватели, guarded crates, конкуренция за реальный лут. Особо интересен **Giant Excavator Pit**: добыть дизель, зачистить штатных учёных, физически заправить, запустить, выбрать ресурс (HQM/sulfur/metal/stone), снимать лут с реальных output piles; не выдавать ресурсы из воздуха. Когда карьер включён игроком или ботом, лишь **некоторые** подходящие независимые группы пытаются атаковать/захватить его, учитывая экипировку, дистанцию, риск, нужду, отношения и cooldown. Не все NPC бегут туда одновременно. Ролевая оборона выходов/двигателя, retreat/reinforcement.
- Oil rigs и cargo ship — **необязательные** stretch-goals; не тормозить из-за них проект. Semantic Pack (русскоязычные реплики) — предпоследний/последний этап, только после зрелых реальных механик.

## Рекомендуемая последовательность (не номера задач)

Дальний outdoor travel и loot → реальные инструменты/добыча/инвентарь → crafting/blueprint/bench economy → first-house blueprint/TC/upkeep/home-local navigation → deaths/bags/respawn/rebuild → PvP/group defense/ambush → RT/cards/scientists → excavator event → масштаб/симуляция 50–100 → Semantic Pack. Разбивать на укрупнённые проверяемые задачи с отдельным новым чатом Codex и GitHub audit, не обещать весь список после одного прототипа.
