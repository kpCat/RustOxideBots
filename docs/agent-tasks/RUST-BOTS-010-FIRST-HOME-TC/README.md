# RUST-BOTS-010 — First Home, TC, Door & Navigation

**Новый диалог Codex; мышление HIGH.** Один укрупнённый gameplay-сценарий после подтверждённой 009, не очередной рефакторинг окружения.

Репозиторий: `D:\Codex\repos\RustOxideBots`, публичный `https://github.com/kpCat/RustOxideBots`, ветка `master`. Проверенная на момент постановки база: `648fbb1520e25bd1ac1b8f328c6d4d36e2a5641f`. Перед началом перепроверить HEAD/local origin/master/публичный master; не делать force/reset.

**Цель:** один `ScientistNPC : BasePlayer` реально строит небольшой 1x1 дом на подходящем месте актуальной карты, устанавливает настоящий шкаф TC, оплачивает строительство и upkeep добытыми ресурсами, открывает/закрывает дверь и физически проходит внутрь/наружу; дом и его привязка переживают независимый перезапуск RustDedicated без двойного строительства.

Сложность возможна — честный `PARTIAL` предпочтительнее ложного GREEN. Самостоятельный test-runner, без ручных команд владельца. Никаких нефтянок/карго/кланов/сотни ботов в этой задаче.
