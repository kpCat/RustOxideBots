# RUST-BOTS-005 — Crafting Recipes & Gates

Старт новой независимой задачи Codex, **High**. Репозиторий `D:\Codex\repos\RustOxideBots`, удалённый `https://github.com/kpCat/RustOxideBots`, ветка **master**. Утверждённая начальная версия: `d9147f18a6e4671cb76d3c042e9d85f2f2f18639` (сначала сравнить с фактическим локальным и удалённым HEAD).

Распаковать ZIP в корень репозитория с сохранением путей; тогда файлы попадут в `docs/agent-tasks/RUST-BOTS-005-CRAFTING-RECIPES/`. Запустить `/goal` из `GOAL.txt` в **новом** чате Codex. Не запускать руками сервер, PowerShell, SteamCMD или тесты — этим занимается Codex.

Поставляется только **задача**, не готовый код и не утверждение об успешном тесте.

**Основная цель:** один автономный Gen2 NPC, имеющий реальные добытые ресурсы, способен подобрать доступный **фактический** рецепт установленной версии Rust, изготовить предмет за счёт ингредиентов собственного native ItemContainer, подтвердить ограничения рецептов и пережить restart без дублирования.

Сложность отдельной большой подсистемы верстаков/технологического дерева и нативного `BasePlayer` не смешивать с этим первым доказанным крафтом. Их изучение входит в обязательный API gate, полноценная реализация — по фактической возможности без ложного GREEN.

Файлы: `TASK.md`, `GATES.md`, `ACCEPTANCE.md`, `EVIDENCE.md`, `HANDOFF.md`, `RISKS.md`, `GOAL.txt` и этот `README.md`.
