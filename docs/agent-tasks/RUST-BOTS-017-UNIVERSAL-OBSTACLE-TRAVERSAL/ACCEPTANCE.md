# ACCEPTANCE — критерии для универсального движения

| Capability | Required proof |
|---|---|
| Generic API | Called from `FirstHome` **and** at least one outdoor destination; no own foundation/netId/seed assumptions inside core |
| Same actor | native `ScientistNPC : BasePlayer` with actual inventory/held and authentic body/capsule; zero identity/health/physics cheats |
| Native path | RustNav route calculations, actual path corners/terrain and bounded replans, clear classification of `PathComplete` vs physical traversability |
| Real step | one observed **safe height transition** (up) using installed native movement or an approved physics-safe controller; continuous live foot support, no collision pass-through |
| Down/slope | independently proved downward/slope/support handling or bounded refusal where unsafe; no flying or snapping to target Y |
| Wall/door | vertical solid/closed locked door remains blocked or causes real legal detour; own unlocked door may open by authenticated native interaction |
| Building | real native paid diagnostic foundation/doorway/door with physical safe in/out or explicit not proven; fixture not production progress |
| Terrain | separate real natural outdoor incline/obstacle class, physical path+contact and exact native support |
| Safety | full body swept capsule/contact/ground measurements and no sustained penetration; nonphysical kinematic clip always fail |
| Performance | bounded local lookahead/repaths, recorded probe frequency/casts and latency/alloc proxies; *not* pretend 100-bot scalability was tested |
| Packaging | native Oxide compile/load and Test-All/negative fixtures, Server/unchanged, all test PID/ports/firewall cleared, encoding/secret check, staged SHA and normal push |

**GREEN_TRAVERSAL_CORE** is a navigation milestone only, **NOT** an autonomous natural home or crash-safe persistence claim. Build-only fixture smoke never counts as NATURAL economy. Real NATURAL+HOME_RESTORE belongs to 018 after core proven.
