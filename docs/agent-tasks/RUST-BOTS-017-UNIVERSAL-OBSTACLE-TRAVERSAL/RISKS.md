# RISKS & ROADMAP — design consequences

- **Native kinematic limitation:** RustNav syncs movement but does not prove collision solver. If no installed full-body safe mover, do not silently enable penetration or rewrite actor class: discuss with owner alternative `native motion bridge` vs `physics-aware local controller` with complexity and future compatibility. A shared probe without real motion is a PARTIAL, not a universal implementation.
- **Universal ≠ any obstacle:** Solid building walls, locked doors, mountains, very tall steps, unsupported drops are not necessarily traversable; solver must choose detour or fail. User wants believable survival, not superhero climbing or flying. Distinguish stairs vs jump: jumping/falling are later supported abilities only if proved safe and chosen by owner.
- **World variants:** no seeded coordinates/resource positions in product, use loaded terrain/building/socket/native map API, separate MapKey/WipeId from mutable save; natural custom/multi-map not fully tested.
- **Concurrency/performance:** rich physics on 50–100 bots can overwhelm frame time. Use local sensors activated around obstacles, route cache + LOD, bounded repaths; include instrumentation but do not claim 100-bot load tested in 017.
- **Security:** owner world/Steam/Rust/Oxide untouched, no network exposure or foreign PID kill. Raw credentials private. Test fixture/native construction paid only inside isolated world; no natural reward.
- **Compatibility:** original tests 001–016 must pass; 009 durable depletion after GRACEFUL restart, but crash-atomic NOT_PROVEN. Future full HOME_RESTORE must rebind owner carefully without foreign TC permissions.
- **Next:** 018 natural paid house+TC/upkeep+door+independent restore using shared traversal. Then general road/loot/nav robustness, real storage and workbench/research, bags/death/respawn, loss-of-TC rebuild/defense, clans/PvP/raids, Giant Excavator with diesel, scaled 50–100 bots, optional oil rigs/cargo, Semantic Pack last.
- **Owner preference:** irreversible architecture/mode decisions discussed with him; code/test/diagnostic routine autonomous. Explicitly document agreed design and risk; no endless narrow door-only rounds.
