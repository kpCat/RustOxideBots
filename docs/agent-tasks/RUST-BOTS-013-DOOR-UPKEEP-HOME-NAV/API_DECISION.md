# API decision 013

Исследование STATIC_IL выполнено по установленным DLL без загрузки и исполнения игровых сборок. Offline compile: C# 7.3. Новых зависимостей нет. Raw metadata/IL: `.local/audit/home013/nav-upkeep-door-il.txt`, `placement-nav-il.txt`, `door-physics-il.txt`, `physics-api.txt`.

- `RustNavigation.DefaultNavmesh.SamplePosition(NavVector3, out NavHit, Vector3, bool)` вызывает native Recast sample. Его результат отделён от физического ground/capsule. `RustNavMeshAgent.CalculatePath(Vector3, RustNavMeshPath)` рассчитывает путь от реального агента; `PathComplete` принимается только при успешном вызове. Наличие исходного enum/default status без вызова не считается путём.
- `HasPendingTiles()` читает очередь BackgroundTileBuilder. `RebuildTilesInBounds(Bounds, bool)` передаёт bounds актуальным navmeshes; `RebuildTilesUnder(BaseEntity)` собирает bounds с collider. После размещения запрашивается bounded rebuild фактических bounds дома, ожидание ограничено 30 секундами. Readiness до/после и timeout записываются отдельно.
- Старый `Ground` делает один downward ray с высоты 4 м, сравнивает первый hit с terrain, затем отвергает любой capsule overlap. Roof, own NPC и собственная геометрия могут давать отказ; какой именно сработал в 012, остаётся UNKNOWN. Shadow probe воспроизводит этот composite в новом smoke, сохраняя sample, первый collider, normal, terrain delta, water и overlaps. Новая проверка использует RaycastAll и допустимую ближайшую опорную поверхность на уровне feet. Собственная foundation допускается только как пол; её коллайдер над feet, TC, стены и любые чужие объекты остаются препятствиями. Self-collider исключается только для собственного actor.
- Точки подхода выбираются относительно фактических foundation/doorway/socket transforms. Текущая позиция используется только после sample/floor/capsule/complete path/LOS/range/permission проверки. Позиции actor не записываются. Native Planner повторно выполняет реальные placement-проверки от фактических eyes.
- `Planner.DoBuild(Construction.Target, Construction)` и target semantics сохранены по 012. Для Door нужен настоящий female doorway socket; единственная оплаченная попытка, реальный возвращённый Door и exact debit `door.hinged.wood`. `Spawn` shortcut не добавлен. Native Phrase/debug сохраняются при null.
- `BuildingPrivlidge.CalculateUpkeepCostAmounts(List<ItemAmount>)` суммирует реальные DecayEntity costs с native tax/group multipliers, включая дверь. `CalculateUpkeepPeriodMinutes()` возвращает серверный native period. `GetProtectedMinutes(true)` пересчитывает protection из реального inventory. В telemetry сохраняются fractional native costs, округлённый резерв, period, before/after и исходные перенесённые UID. Требование приёмки — минимум 60 минут, а не обязательная оплата полного native периода; free prior credit отвергается.
- Native `Door.SetOpen(bool,bool)` меняет flag и запускает native state path. `Door.OnFlagsChanged` обновляет collider roots и `RustNavDoorGates.OnDoorToggled`; AnimatedBuildingBlock обновляет Animator. Существующий runner проверяет изменение настоящих collider/state, aperture и непрерывный физический вход/выход. Сам flag ещё не доказывает проход.

STATIC_IL и focused synthetic validator fixtures не доказывают live дверь, upkeep или HOME_NAV. Фактический результат и отсутствующие доказательства фиксируются в RESULT.md после разрешённых запусков.
