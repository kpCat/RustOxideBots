At first persistent/wall/foreign penetration, fail closed.

If a true native step/structural alternative is used: specific installed prefab/socket/grade/item blueprint, native entity type/owner/buildingID, native support and cost, location **relative to house**, actual RustNav surface/support height, before/after physical contact proof. Do not claim hypothetical or free steps.

## Smoke versus natural

Smoke: exact TEST_FIXTURE amounts+UID/payments; actual 6+ native blocks, TC own-auth, transferred original wood to TC, protection≥60m, door open/close, both crossing events and REAL support/clearance. Strict no-promote. Natural: independent clean run, no test fixture, actual native trees/ore pool payments/tool wear/blueprints/TC/build, durable journal, native actor/house snapshot. Restore: exact .sav/generation/map+wipe keys/source hashes, `fromDisk` structural witnesses, original Item UIDs/held, no craft/harvest/build/kit replay, physical passage and no foreign mutation.
