# API_GATE — обязательная проверка до live запуска

Изучить текущие установленные DLL/IL и **точно локально** подтвердить сигнатуры и lifecycle для:

1. `ScientistNPC : NPCPlayer : BasePlayer`, конкретный установленный `ScientistNPC_Roam.prefab` и его `PlayerInventory`/`NPCPlayerNavigator`/`RustNavMeshAgent`. 006 уже нашёл `Native ResetPath -> desiredSpeed=0`; `SetDestination` сам не восстанавливает скорость. При каждом новом маршруте выставлять скорость после SetDestination. Отдельно исключить конкурирующие `brain.TickMovement` и wake/sleep только для собственного NPC, не для всех NPC мира.
2. Инициализация native PlayerInventory main/belt/wear, `Item.GetOwnerPlayer`, `Item.MoveToContainer`, `BasePlayer.UpdateActiveItem(ItemId)`, `GetActiveItem()`, `GetHeldEntity()`. Исследовать, как штатный ScientistNPC загружает дефолтные MP5/сиринг/костюм и как безопасно нормализовать **только test actor** до начального kit без потери/дублирования. Нельзя считать наличие `Item` в main эквивалентом предмета, который держат в руках.
3. `ResourceEntity`, `TreeEntity`, `OreResourceEntity`, `ResourceDispenser`, `HitInfo`, `BaseMelee` и нативный путь `BasePlayer`-gather. 004 обнаружил, что для Gen2 native yield блокируется `InitiatorPlayer=null`; после перехода на `BasePlayer` это может измениться. **Исследовать и по возможности проверить native harvest на этом реальном actor, прежде чем продолжать accounted adapter**. Нельзя одновременно допустить native gather и вручную начислить тот же ресурс.
4. `ItemBlueprint`, `ItemCrafter`, `PlayerBlueprints`, фактический рецепт `stonehatchet` и его ингредиенты/цена/bench/known gates. Пригодность native player queue проверять по сигнатурам и при необходимости одной ограниченной live-попыткой; если невозможно без игрокового соединения — честный SERVER_ACCOUNTED_CRAFT, без поддельной нативности и без фиктивных 15 секунд.
5. Нативная сериализация `PlayerInventory` и его контейнеров (если доступно), восстановление реальных UID+amount+condition+slot, затем exact activeItem; фактический `HeldEntity` после рестарта. Обязательны world cache generation, saved .sav SHA, snapshot SHA и stable logical actor ID. Если нативный actor сам сохраняется в .sav — не дублировать предметы восстановлением из другого источника. Все reconcile before/after.
6. Персональные игроковые API/Steam: **никогда** не назначать подставные настоящие Steam IDs, не создавать фальшивое подключение, не наследовать чужие права/техдерево/кланы. Системно выделенный NPC bot ID допустим только как engine runtime ID, не объявлять долгоживущей личностью.

В `API_DECISION.md` ссылайся на реальную сборку и методы: STATIC/IL, офлайн fixture и LIVE_PROVEN разделять. Не переписывать тексты прежних API_DECISION задним числом.
