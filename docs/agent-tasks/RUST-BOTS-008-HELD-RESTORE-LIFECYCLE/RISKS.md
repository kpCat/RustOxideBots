# RISKS — не потерять контекст после 008

1. **Transient HeldEntity:** saved `heldEntity` network ID может совпасть с entity нового процесса; старый `net ID` не является постоянным item ID. Только доказанный in-memory native restore, не удаление чужих сетевых объектов. Требуется контролировать repeated parent reinitialization, возможный double HeldEntity и item ownership.
2. **World proof drift:** 007 независимый RESTORE мог продвинуть/перезаписать тестовый cached world `.sav`; прошлый snapshot без exact generation/hash может быть непригоден. Не обходить сопоставление и не копировать owner save. Если старый world proof недоступен, новый JOURNEY+RESTORE вместо ложной преемственности.
3. **Переносимость UID:** сохранение Item UID важно, но новый `NPCPlayer`/native container может получить другие сетевые ID. Validator должен сравнивать неизменяемые предметные атрибуты и роли, а owner/containers — относительно нового actor, не требовать старый net ID. Если native container UID сохраняется — зафиксировать как факт, не предполагать заранее.
4. **Неравная физическая игра:** 007 native gather подтверждён; crafting пока **SERVER_ACCOUNTED_CRAFT** из-за отсутствия `ItemCrafter` на Roam. No visual client animation, combat, clans or bases.
5. **Production economy остаётся небезопасной:** истощение `ResourceDispenser` между рестартами не сохранено; нет устойчивого crash-atomic craft journal. После 008 следующая крупная задача — **WORLD-ECONOMY-PERSISTENCE**, отдельно и с реальным restart/crash-recovery proof, до десятков долгоживущих ботов.
6. **Сохранить широкую цель:** 50–100 персон, старт на пляже, фарм/лут/крафт, верстаки/blueprint, TC/upkeep/дома/двери/ящики/сортировка, спальник/смерть/respawn, PvP/кланы/рейды, Giant Excavator Pit. Oil rigs/cargo необязательны, Semantic Pack поздно. Не пытаться реализовать их в 008.
7. **Лимиты и безопасность:** не более двух live tests, третий только при доказанной причине; даже при проблемах сдавать честный PARTIAL/BLOCKED, не вызывать пользователя запускать BAT/PowerShell. Только один owned test process, auto cleanup; текущую установку Rust/Oxide не обновлять.
