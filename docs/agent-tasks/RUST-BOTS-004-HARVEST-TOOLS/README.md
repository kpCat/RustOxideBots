# RUST-BOTS-004 — Harvest & Tools

Это **следующая отдельная задача Codex**, не продолжение беседы 003. Цель — перейти от сценарного loot к добыче базовых природных ресурсов с реальной экономикой, попытаться прикрепить игровой инструмент к нашему физическому NPC и выяснить, что доступно без BasePlayer.

Распаковать архив **в корень** `D:\Codex\repos\RustOxideBots\` с сохранением относительных путей; все документы окажутся в `docs/agent-tasks/RUST-BOTS-004-HARVEST-TOOLS/`. Открыть **новый чат** Codex в корне репозитория, выбрать **High**, вставить команду из GOAL.txt. Не распаковывать в Server/ и не запускать owner BAT.

Перед выполнением изучить TASK, ACCEPTANCE, HANDOFF, EVIDENCE, GATES; следовать AGENTS.md и текущим исходникам. Архив содержит только постановку — **ни один файл установленного сервера не меняется** при распаковке.

Обязательная поставка Codex: работающий код или честный частичный результат, E2E receipts, RESULT.md, безопасный exact-path commit, обычный `push origin master`. После выполнения отчёт проверяется по публичному GitHub и отличается от независимого live-подтверждения только наличием локальных raw evidence.
