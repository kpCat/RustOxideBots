# ACCEPTANCE — проверка результата

## GREEN (всё обязательно)

- [ ] Публичный Git содержит только источник/документы/скрипты; `Server/` игнорируется на 100%, проверены `git check-ignore`, `git diff --cached --name-only` и скан секретов; `Server/` отсутствует в `git ls-files`.
- [ ] Работает понятный test-runner, изолирующий test identity/порты/секреты **и записываемые Oxide plugins/config/data**; без SteamCMD.
- [ ] Оба BAT проанализированы и безопасно улучшены с бэкапами или сохранены оригиналы с честным PARTIAL. Исправлены относительные пути; чистый выход не приводит к бесконечному рестарту; апдейтер отказывает до SteamCMD, если нельзя вернуть совместимый Oxide. Статические/dry-run/mock-проверки, никаких реальных обновлений.
- [ ] Реальный сервер подтверждённо дошёл до ready; Oxide и diagnostic plugin загрузились без ошибки компиляции.
- [ ] Фактическое движение 1 NPC: 3 динамически проверенные достижимые цели, суммарный реальный путь >= 60 м, хотя бы один переход >= 20 м, без теле-перемещения после рождения; raw telemetry + сводка.
- [ ] При любом исходе test-runner завершил **только свой** серверный PID; отсутствие процесса и портов проверено.
- Startup inventory/measurement, сохранность основных файлов и плагинов подтверждены; зафиксированы хеши бэкапов BAT и защита пользовательских данных/Oxide-каталогов.
- [ ] RESULT.md с проверками, итоговым SHA, доказательствами, честными ограничениями, `git push origin master` прошёл.

## PARTIAL / BLOCKED / FAILED

`PARTIAL` — есть работающий безопасный harness, но неполная навигация. `BLOCKED` — невозможен честный E2E из-за окружения/API/запуска/используемого владельцем сервера. `FAILED` — изменения нарушили контракт или тест неработоспособен. Не заявляй GREEN, если NPC создан, но стоит, или только меняется Vector3 вручную.

В любой ситуации завершение тестового процесса и отсутствие публикации Server/ и секретов — инварианты, а не необязательная проверка.

## Метрики

- Версии RustDedicated и Oxide; выбранный Nav backend, NPC concrete prefab/type/brain/agent.
- Точный startup timeline (world/map/Oxide/plugins/ready), сравнение `.map/.sav` с параметрами.
- Каждая navigation leg: start/target/end, status, elapsed, total traveled, net displacement, stuck/repath count, failure reason.
- PID процесса, когда запущен, exit/result shutdown, остаточные процессы.
- Гит: исходный SHA, новый SHA, изменённые paths, `git status --short`, `origin/master`.
