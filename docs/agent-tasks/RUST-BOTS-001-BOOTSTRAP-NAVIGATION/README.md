# RUST-BOTS-001 — безопасный фундамент + первая живая навигация (обновлённая задача v2)

## Где распаковывать

Архив содержит папку `docs/`. Распаковать **в корень** `D:\Codex\repos\RustOxideBots\`, а не внутрь `docs`. Тогда задача окажется в `docs/agent-tasks/RUST-BOTS-001-BOOTSTRAP-NAVIGATION/`.

Если старый архив уже распакован, распаковать **v2 поверх с заменой одноимённых файлов**. Если Codex уже выполняет 001, не начинать ещё один запуск параллельно: передать ему новые файлы.

Далее открыть **новый чат Codex** в уже открытом репозитории и вставить текст из `CODEX_LAUNCHER.txt` (с командой `/goal`). Рекомендуемое размышление: **High**.

Это не готовый плагин и не модификация пользовательской установки. Это ТЗ для Codex, имеющего доступ к локальным файлам Windows.

### Исходные вводные

- Repository: `https://github.com/kpCat/RustOxideBots` (публичный), базовая ветка `master`.
- Local: `D:\Codex\repos\RustOxideBots\`.
- Сервер: `Server\` (~6.6 ГБ); точную структуру сверить на диске.
- Запуск владельца: `Server\Run_DS.bat`.
- SteamCMD/обновления: `Server\update.bat`; **не запускать**.
- Oxide plugins: `Server\rustds\oxide\plugins\`.
- Oxide configs: `Server\rustds\oxide\config\`.
- Пользовательские настройки ориентированы на одиночную игру, ничего не сбрасывать автоматически.
- Первое требование: сервер с новым Oxide уже обновлён, запрет на повторный апдейт.
- v2: пользовательские BAT уже изучены, `Run_DS.bat` бесконечно перезапускает сервер, `update.bat` не возвращает Oxide; попросили улучшить скрипты с резервным копированием и без реального обновления.
- v2: отдельная `server.identity` сама по себе недостаточна для изоляции каталогов Oxide. См. `BAT_AUDIT.md`.

### Цель одним предложением

Доказать безопасный автоматический цикл запуска/завершения RustDedicated без игрового клиента и первый **фактический** путь NPC по серверному NavMesh, одновременно защитив публичный Git от игровых данных, пользовательских конфигов и секретов.
