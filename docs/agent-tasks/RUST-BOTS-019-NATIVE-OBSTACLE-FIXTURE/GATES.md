# Stage gates / budget

| Stage | GO requires | STOP means |
|---|---|---|
| G0 Baseline | HEAD/local/public equality, no foreign edits, owner/server isolated, AGENTS | unsafe checkout or owner process |
| G1 Offline | native API/fixture design, source RED→GREEN for read-only refusal, combined C#7.3, Test-All, independent reviewer | guessed prefab, free/fake spawn, unsafe negative probe |
| G2 Physical site | actual safe site from native preview with dynamic map transform, genuine paid fixture without owner mutation | if no valid native placement after bounded scan, `NO_NATIVE_SITE` not repeat infinite |
| G3 Controller baseline | original full body, physics fixed/wall clock & supported motion, no clipping or unsafe commands | any native discrepancy, STOP |
| G4 Obstacles | measured actual wall & closed native Door negative refusal separately; bounded actual detour around finite external wall; no internal sealed-door bypass | wrong collider/unauthorized mutation, fake detour; `G4_PARTIAL` |
| G5 Home | full paid native 1×1 TC/upkeep/auth, open Door, complete physical IN/TC/OUT/close and true discrete threshold transition | `G5_UNSAFE` / `G5_NOT_TESTED` |
| G6 Release | tests/reviews/safety/privacy/owner check/exact commit/push, no default product enable | no green on partial |

Absolute max3 new live starts total. If G2 cannot find any valid native site on Start1, use read-only diagnostics to fix *known* site condition; Start2 only with genuine fix after independent review. Never launch Start3 to repeat unchanged site scanning. If Start1 reaches G4 but G5 fails, target Start2 to measured bug/geometry issue while preserving existing G4 receipt and not overstate G5. Best output is transparent per-gate evidence even when overall PARTIAL.
