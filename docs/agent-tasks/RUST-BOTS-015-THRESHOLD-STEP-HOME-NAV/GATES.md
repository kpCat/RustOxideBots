# Stop / go последовательность

| Gate | Стоп/переход |
|---|---|
| G0 BASELINE | local HEAD/tracking/public master = expected or safely reconciled; tree no foreign edits; owner protected and ignored |
| G1 STATIC_IL | actual native motion/portal/physics and journal/path contracts inspected. RED→GREEN fixtures, independent review and Test-All before live; no invented API |
| G2 SMOKE_1 | one real native home+paid TC/door/upkeep and complete OUT→IN→TC→OUT→CLOSE with truthful body contacts and native motion |
| G2 FAIL | no concrete safe correction => PARTIAL; specific supported correction => offline review and at most SMOKE_2, then stop this task |
| G3 NATURAL | only after G2 passes on the **first** smoke, one new natural paid home with completed save/WorldKey. No TEST_FIXTURE in economy |
| G4 RESTORE | only with G3 confirmed: independent process native original home/items/identity/TC, no replay, physical home path |
| G5 DELIVERY | full tests/review/safety/secret/encoding audits, exact-file commit and ordinary push; no owner or historical file changes |

Game processes 3 max; `SMOKE_2` consumes the slot otherwise used for NATURAL/RESTORE and task **stops after it**, irrespective of smoke outcome. Do not start a lonely natural without a restore slot. FirstHome smoke diagnostic cache is never promoted; no local reuse of partial 014 world.
