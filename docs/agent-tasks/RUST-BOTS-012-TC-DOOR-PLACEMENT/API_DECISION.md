`Planner.DoBuild(Target,Construction)` проверяет owner, конечность ray/position/normal; сбрасывает ошибки; проверяет female/occupancy/onTerrain конфликт, AntiHack inside и LOS, sleeping-bag admission; затем `DoPlacement` → `CreateConstruction` → `UpdatePlacement`, hook `OnConstructionPlace`, spawn/payment и `OnEntityBuilt`/native postbuild. Early AntiHack/LOS null может оставить ошибки пустыми; native Phrase и debug не взаимозаменяемы. Вызов с ProtoBuf дополнительно проверяет item/definition/affordability/hook/target и parent semantics; adapter сохраняет эти проверки явно.

`UpdatePlacement` проверяет target/permission, selected male socket, socket mods, rock/wall/LOS/road, distance, DeployVolume, BuildingProximity, TC overlap privilege, building-blocked и hold duration. В конце пустого socket-list возвращает false. `Construction.lastPlacementError`, `.lastPlacementErrorDebug`, `.lastPlacementErrorIsDetailed` и `.lastBuildingBlockError` публичны. Phrase `.translated` подтверждён IL и compile. Protected instance LOS не вызывается reflection: public static `Planner.HasLineOfSight(ref Placement,Construction,Target)` даёт тот же TC no-alternative LOS путь; финальный DoBuild всё равно повторяет native проверки.

Два preview используют только пустой scratch Transform и native `UpdatePlacement`; не вызывают `CreateConstruction`, `CreateEntity`, `Spawn`, оплату или выдачу Item. Проверяются неизменность entity count и exact inventory, сохраняются/возвращаются shared diagnostic fields. Telemetry содержит active item/held/planner, target/ray/surface collider, capsule/OBB/overlaps, nearby structure, native preview/Phrase/LOS/DeployVolume/permission. Legacy preview не является оплаченной попыткой. Ни одна ошибка не подделывается. Ровно одна native TC попытка; незавершённый payment intent не повторяется.

Первый smoke 012 остановлен добавленной диагностикой до TC: `UnityEngine.Object.get_name` → `HomePreviewTc`. Вместо native getter используется подтверждённое `PrefabAttribute.fullName`. Offline regression читает emitted IL реального compiled home plugin без загрузки game assemblies: прежний getter обнаружен (RED), исправленный вариант обязан исключать его.
